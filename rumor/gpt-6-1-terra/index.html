OpenAI releases a cheaper GPT-6.1 Terra model that beats GPT-6.1 Sol

The claim

OpenAI is about to release GPT-6.1 Terra, a new model in its Terra tier that outperforms GPT-6.1 Sol while costing less.

Why we rated it Confirmed

Two separate signals: a Microsoft pull request switched 18 evaluation configs from GPT-5.6 Terra to GPT-6.1 Terra, and The Information reported a new Terra model is coming. The model's existence is well supported, but the 'better than Sol for less' part comes only from The Information's paywalled report, and its reporter said some launches may slip into November. OpenAI has said nothing. Update Oct 26-27: OpenAI announced GPT-6.1 Terra on Oct 26. It is available to Plus, Pro, Enterprise and Edu users and in the API as gpt-6.1-terra at $1 per million input and $5 per million output tokens, 50% below GPT-6.1 Sol. OpenAI pitches it on computer use, saying it is over three times faster than Sol and GPT-6 Astra on its task benchmark, nearly matches them on MMMU-Pro and surpasses Sol on Terminal-Bench-Science, but recommends Sol or Astra for the most complex coding.

Outcome

Mostly true. OpenAI released GPT-6.1 Terra on Oct 26 in ChatGPT Work, Codex and the API at half the API price of GPT-6.1 Sol. OpenAI's own benchmarks show it beating Sol on some tests (Terminal-Bench-Science) and nearly matching it on others, but OpenAI says Sol remains the better pick for the hardest coding work, so 'beats Sol' was only partly right.
