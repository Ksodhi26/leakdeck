The claim

Meta's next model, Muse Spark 1.4, is already running inside Meta's internal tools ahead of any public release.

Why we rated it Likely

A public pull request on Meta's RocksDB GitHub repository includes auto-generated test notes showing a real call to 'muse-spark-1.4-internal' (about 33,500 input tokens, 8,169 output tokens, 65 seconds), spotted by @LuminaBench and reported by TestingCatalog. That is hard evidence the model exists internally, so it is Likely. The internal name may change, and there is no word on release date, benchmarks or price; Meta has not commented.
