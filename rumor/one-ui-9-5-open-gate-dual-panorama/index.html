One UI 9.5 adds Open Gate full-sensor video and a front-and-rear 'dual cam panorama'

The claim

Samsung's Camera app will offer Open Gate video that records the full sensor area (24 to 60 fps) and a Dual cam panorama that uses the front and rear cameras together for a 360-degree shot.

Why we rated it Likely

Android Authority found strings for both features in the One UI 9.5 beta Camera app, relayed by GSMArena and SamMobile. Code is solid evidence Samsung is working on them, but code features do not always ship, and which phones get them is unknown.
